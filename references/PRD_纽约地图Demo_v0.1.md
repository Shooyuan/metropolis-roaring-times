# 《大都会：咆哮年代》—— 纽约单城地图 Demo PRD

**版本**：v0.1  
**文档类型**：产品需求文档（PRD）  
**目标平台**：PC（首发），后续考虑移动端  
**Demo 范围**：单一城市（纽约 Manhattan + 部分 Brooklyn），单机人机对战，3 名 AI 对手  
**预计 Demo 时长**：45—90 分钟 / 局

---

## 一、项目概述

### 1.1 一句话描述

一款以 1920 年代纽约为背景的大战略模拟游戏——玩家通过购买地产、建造公寓/工厂/百货公司/交通设施，在资产交易所与 AI 对手博弈，构筑商业帝国。

### 1.2 核心体验

玩家打开游戏后的第一感：

> "这不是在玩一个抽象的棋盘游戏。我站在 1927 年的纽约第五大道上，街对面是刚落成的 Chrysler Building 脚手架，手里攥着刚从银行借出来的三万美元。对面那个戴圆顶硬礼帽的秃头——我知道他是 AI——刚才在拍卖会上抢了我看中的一块地。下一块地是中央公园南侧的拐角，我势在必得。"

### 1.3 Demo 目标

**不是**做一个"能玩但很简陋"的原型。  
**是**做一块完整、精美、经得起反复测试的**垂直切片**——一张纽约地图，四个完整系统，三种 AI 对手，一个完整的经济周期。这块做好了，加第二座城市（芝加哥）就是复制框架和更换地图数据，而不是重写底层。

### 1.4 不做的事（明确排除）

- 不做过场动画和配音
- 不做多人联机（Demo 阶段）
- 不做完整的教学关卡（用 tooltip + 一张静态引导页替代）
- 不做除了纽约以外的第二座城市
- 不做随机地图生成
- 不做"科技树"或时代演进（Demo 全程固定在 1920 年代）

## 二、世界与时代设定

### 2.1 时间

**1925—1928 年**。游戏开始时约在 1925 年前后。没有确切年份标签（避免历史考证负担），但所有建筑、服装、车辆、广告牌的美术参考取这个时间段。

### 2.2 地点：纽约 Manhattan（布鲁克林作为远景 + 部分可购买区域）

Demo 地图涵盖：

| 区域 | 类型 | 初始状态 |
|---|---|---|
| **下城金融区（Wall Street / Broadway 南端）** | 高密度商业/金融 | 大部分土地已被持有，玩家需要从现有持有者手中收购，或购买零星释放的小地块 |
| **中城（Midtown, 34th—59th St）** | 待开发/半开发 | 大量空地可供首次购买。这是 Demo 的核心区域——玩家在这里做大部分首次购地决策 |
| **中央公园南北两侧（Upper East Side / Upper West Side 南端）** | 高价值住宅用地 | 地价极贵，早期无法染指；后期"声望"达标后可解锁购买资格 |
| **地狱厨房 / 下东区（Hell's Kitchen / Lower East Side）** | 工业/住宅混合 | 便宜、可建工厂、但住宅租金低、污染指标高 |
| **布鲁克林桥头区域（DUMBO 方向）** | 新兴待开发区 | 地价最低、初始回报率低、但交通设施（地铁、桥梁）的建设可使其价值翻数倍——鼓励长线投资 |

### 2.3 不可购买的地块

以下地块在 Demo 中为"政府持有"（不可购买，但提供公共效应）：

- 中央公园（提升周边住宅租金）
- 市政厅
- 公共图书馆（+声望）
- 地铁系统（初始覆盖有限，玩家可自建延长线）
- 布鲁克林大桥 / 曼哈顿大桥（固定存在，提升布鲁克林侧地块价值）

## 三、美术与视觉风格

### 3.1 总体方向

**基准**：Cuphead（1930 年代 Fleischer Studios 橡皮管动画风格）  
**叠加**：20 世纪早期旅行海报的色调、字体、装饰边框  
**附加**：Art Deco 建筑线条（克莱斯勒大厦、洛克菲勒中心、Radio City Music Hall 的几何立面）

### 3.2 具体美术要求

| 元素 | 处理方式 |
|---|---|
| **地图前景** | 手绘感街道网格 + 建筑剪影（有厚度感，非扁平矢量）。每个地块上已有或待建的建筑以 3/4 侧视角绘制，类似老明信片的透视感 |
| **地图背景** | 天空为渐变的旅行海报式晚霞或晨曦；远处布鲁克林天际线为半透明剪影 |
| **角色立绘** | 橡皮管风格——圆眼睛、白手套、橡皮管手臂。AI 对手在交易所竞价、正面交锋时以半身立绘 + 气泡对话出现 |
| **UI 面板** | Art Deco 几何边框 + 铜绿色/金色/奶油色调。按钮为浮雕感，字体为无衬线大写（如 Broadway 招牌风格） |
| **字体** | 英文使用类似 Futura / Gotham 的无衬线几何字体（20 年代 Art Deco 标准字体），中文使用方正粗宋或类似的黑体—宋体之间的粗重笔画字体 |

### 3.3 声效与音乐参考

**音乐**：Ragtime → 早期爵士（Dixieland Jazz）→ 大乐队摇摆的过渡期风格（1925—1928 年间）。非背景循环，而是根据玩家行为动态切换强度——平静时（浏览地图）为散板钢琴 ragtime，竞价时加入铜管，接近胜利时切为大乐队 full band。

**声效**：打字机（交易确认）、老式电话铃声（AI 来电谈判）、报纸印刷机（新闻事件触发）、汽车喇叭（地产成交）、老式收银机"叮"一声（租金入账）。

## 四、核心数值（Demo 版本）

### 4.1 玩家资源

| 资源 | 简称 | 初始值 | 用途 |
|---|---|---|---|
| **现金** | 💵 | $50,000 | 购地、建楼、日常维护费、竞标保证金 |
| **信用额度** | 🏦 | $100,000 | 大额收购、竞标超出保证金部分。信用额度 = 持有资产总值的 60% × 银行系数（初始 1.0，随信用记录浮动） |
| **声望** | ⭐ | 0 | 解锁高级地块（中央公园周边）、解锁豪华建筑类型（高级公寓、百货公司）、获得政府招标优先权 |

三者不可直接换算。每一项获取方式不同（现金靠租金/出售资产，信用靠持有资产总值，声望靠建地标/持有文化类建筑/捐赠市政项目），消耗场景也不重叠。玩家被迫同时管理三条线。

### 4.2 地块属性

每个地块（tile）在数据结构中包含以下字段：

| 字段 | 说明 |
|---|---|
| `land_value` | 当前市场地价（受周边建筑、交通、城市繁荣度、事件影响而动态变化） |
| `zone_type` | 住宅 / 商业 / 工业 / 混合 / 公共（不可购买） |
| `building` | 当前建筑（可为空 → 空地） |
| `owner` | 当前持有者 ID（玩家 / AI_x / 政府） |
| `adjacency_bonus` | 相邻加成数组（相邻的交通设施 +15%，相邻的工厂对住宅 -20% 等） |
| `monopoly_flag` | 该地块所在城市—区域—类型中，持有者是否达到垄断比例 |

### 4.3 四类建筑的成本与回报（Demo 数值，后续通过测试调整）

| 建筑 | 建造成本 | 每回合维护 | 每回合收入 | 特殊效果 |
|---|---|---|---|---|
| **普通公寓** | $8,000 | $200 | $600—$1,200 | 稳定现金流；受周边工厂（-20%）和交通设施（+15%）影响 |
| **高级公寓** | $25,000 | $800 | $2,000—$4,000 | 仅可建在声望值达标 + 周边无工厂的地块 |
| **工厂** | $15,000 | $500 | $1,000—$2,500 | 可形成产业链（需同城或相邻城有其他关联工厂）；降低周边 2 格内住宅租金 20% |
| **百货公司** | $30,000 | $1,000 | $1,500—$5,000 | 收入取决于所在城市**所有玩家**住宅单元总数 × 系数。即：别人建住宅你建百货公司，你赚别人的客流 |
| **有轨电车轨道** | $5,000/段 | $100/段 | 无直接收入 | 周边 2 格所有建筑收入 +15%；三段以上连成线路则加成提升至 +25% |
| **地铁延长线**（解锁需声望） | $20,000/站 | $300/站 | 每站每回合微量票务收入 | 周边 3 格所有建筑收入 +20%；整条线路的每个车站所在区域的过路费由建造者征收 |

### 4.4 经济周期（Demo 版本）

每局游戏约 50—70 回合（一回合 = 游戏内"一个月"）。周期分段：

| 回合 | 阶段 | 特征 |
|---|---|---|
| 1—8 | 开局 | 地价低、大量空地、银行贷款宽松（利率 3%）、AI 策略保守 |
| 9—18 | 繁荣期 | 地价持续上涨、交易活跃、银行利率 2%—4% |
| 19—26 | 过热期 | 地价泡沫化（虚高）、银行开始收紧贷款（利率升至 6%—8%）、随机触发"股价回调"或"罢工"事件 |
| 27—32 | 调整期 | 地价回落 20%—40%、现金充裕的玩家可以抄底收购 AI 被迫抛售的资产 |
| 33—50+ | 第二周期 | 新的繁荣—过热—调整循环，但波动幅度加大（因为各个玩家的帝国规模都比开局大了数倍，每次波动牵动的资本量更大） |

**设计意图**：不是让数字线性增长到天荒地老。周期迫使玩家在"进攻（繁荣期贷款扩张）"和"防御（过热期减持、套现、保留大量现金）"之间切换。

## 五、核心系统

### 5.1 地产购买与拍卖

**普通购买**：玩家点击空地 → 弹出该地块信息卡（地价、zone 类型、周边加成一览、当前挂牌状态）→ 若为空地且无他人挂牌，则可直接以市场价购入。

**竞拍系统**（当多个玩家同时看上同一地块，或地块为"政府释放的稀缺地皮"时触发）：

- 竞拍为**英式公开增价拍卖**：逐轮加价，每次加价增幅不低于上一轮出价的 5%，10 秒内不出价者自动退出
- 出价不能超过"现金 + 信用可用额度"
- 输掉的竞拍者得到"出价返还"（现金部分全额返还），但失去在该回合再次参与竞拍的资格（一回合只能认真打一仗）
- AI 在竞拍中的行为由 AI 人格 + 对这块地的"估值算法"决定（见 5.3）

**竞拍触发条件**：
- 一块空地有 2 名以上玩家同时出价
- 政府定期释放中城区域的地块（每 4 回合一次，一次释放 2—3 块）
- 某玩家触发"资产被强制拍卖"事件（破产边缘时政府介入的财产清算——可被其他玩家以低价竞得）

### 5.2 资产交易所（产权交易）

不是"股票市场"。每一块已经有人持有的地块（以及地块上的建筑），都对应一张**产权凭证**，可以在此交易。

**三种交易模式**：

| 模式 | 说明 |
|---|---|
| **挂牌出售** | 持有者标价，挂牌 2—4 回合。期间任何玩家（人/AI）可原价购买或出价谈判 |
| **封闭竞标** | 持有者发起，指定为"价高者得"模式。所有竞标者暗标出价，一轮定局。适用场景：珍稀地块（中央公园南侧拐角）不想在挂牌中被"捡便宜" |
| **恶意收购** | 如果玩家/AI 在某城市—区域—建筑类型中持有超过 40% 的份额，可向其他持有同类资产的对手发起强制收购要约——比市场价高出 20%—30%。被收购方选择：①接受；②支付更高的价格把收购方已有的那 40% 全部买过来（毒丸策略——如果被收购方现金充裕的话）。若无法支付，则必须接受收购 |

**设计意图**：让"持有"本身不是永远安全的。帝国是动态的——有人可以随时对你的核心资产发起挑战。

### 5.3 AI 系统

Demo 中包含 3 名 AI 对手，每人有明确的人格和策略偏好：

#### AI-A：工业巨头（Cornelius "The Tycoon"）

- **策略核心**：大量建工厂 → 铺设铁路连接工厂群（追求规模效应）→ 利用工厂形成的产业链压低制造成本 → 出售工业品获利
- **强项**：工厂连锁收益极高，中期爆发力强
- **弱项**：现金流经常紧张（工厂建设周期长、占用资金大），衰退期容易被逼抛售资产
- **行为特征**：拍卖中不跟你纠缠小地块；但当他看中了你的工厂群旁边的铁路关键区间时，会以极高的恶意收购溢价出价——他在赌你不敢反收购，因为你不会需要铁路相关的工厂群

#### AI-B：地产大亨（Beatrice "The Landlady"）

- **策略核心**：大量收购住宅用地 → 建设高级公寓 → 提升周边配套（公园、百货公司）以拉高租金 → 现金流充裕后开始涉足商业地产
- **强项**：现金流极其稳定，经济衰退期几乎不受影响
- **弱项**：资产流动性差（大量资金被锁在住宅地产上），面对恶意收购时手中现金不足
- **行为特征**：拍卖中对住宅用地出手果断、对工业用地完全不看；如果她比你早一步垄断了中央公园周边的住宅区，你几乎不可能从她手中抢回来

#### AI-C：金融投机者（Saul "The Shark"）

- **策略核心**：不做实业（几乎不建工厂、极少建设住宅），主要在交易所低买高卖产权凭证。他的资产组合不是"我拥有的地产和建筑"，而是"我以低于市场价收购的、等待升值后卖出的各类凭证"
- **强项**：极度灵活，任何时候都保有大量现金，在衰退期是最大的抄底力量
- **弱项**：没有稳定现金流（不持有可产生租金收入的实业），一旦判断错误（高杠杆持有一块地皮等它升值，结果它跌了 40%），就会遭受毁灭性亏损
- **行为特征**：他不是对手——他更像是游戏里的"搅局者"：在你和 Tycoon 都想要一块地的时候把价格抬到离谱的高位然后放弃（迫使你们中的一个以过高价格购入），他的利润在于制造和利用你们之间的竞争

#### AI 的"人味"

AI 在拍卖中的出价不是固定的算法——它会：
- **在你资金紧张时加价**（它能"看"到你的现金—信用比不健康）
- **在你声望刚刚越过某个门槛、解锁了新权限后选择退让**（"让你尝个甜头"——实际上是它判断你此刻持有过强谈判筹码）
- **在连续三个回合被你击败后进入短暂的过度防御状态**（出价变得过于保守，因为他"心态崩了"）

**设计意图**：不是做三个难度档次的 AI，而是做三个**性格不同、各有所长所短**的 AI。玩家在每局中可以面对其中两人（二人一组的随机组合，加上玩家形成三人局），使得每局体验不同。

## 六、经济事件系统

Demo 版本中设置两类事件：**全局事件**（影响所有玩家）和**局部事件**（影响单一玩家或单一地块）。

### 全局事件（随机触发，经济周期不同阶段触发概率不同）

| 事件 | 触发条件 | 效果 |
|---|---|---|
| "世博会将在纽约举办！" | 繁荣期概率高 | 所有纽约地块地价 +30%，持续 6 回合；旅游类建筑（高级公寓、百货公司）收入翻倍 |
| "联邦储备委员会加息" | 过热期概率高 | 银行贷款利率 +3%；持有大量信用额度的玩家每回合额外支付利息 |
| "股市黑色星期四" | 过热期末尾固定触发一次 | 所有地产估价 -25%；所有玩家信用额度减半（银行收紧贷款）；持现充裕者可在接下来 4 回合内大量低价收购 |

### 局部事件（每回合概率触发）

| 事件 | 效果 |
|---|---|
| "洛克菲勒家族在 Upper East Side 开发新住宅区" | 该区域所有地块地价永久 +15% |
| "地铁公司将延长 BMT 线至布鲁克林" | 布鲁克林桥头区域所有地块地价 +30%（在宣布时已持有地块的玩家获益） |
| "地狱厨房发生劳工罢工" | 该区域所有工厂停产 2 回合（无收入，但仍需支付维护费） |
| "X 银行对 [玩家名] 追加贷款担保要求" | 信用额度临时 -20%，若在接下来 3 回合内未补足等值现金担保，则强制出售其部分资产以清偿贷款 |

**设计意图**：让游戏不完全由玩家的"最佳购入策略"决定。有人在地价最贵的时候买在了高点，半年后被加息和股市回调双重打击——这不是系统惩罚他"玩错了"，而是经济周期本身就是游戏的一部分。

```
├────────────────────┴─────────────────────────┤
│  [建造菜单]  [交易所]  [拍卖厅]  [资产总览]  [结束回合] │  ← 底部工具栏
└──────────────────────────────────────────────┘
```

### 7.2 地图交互

- **鼠标悬停**：地块高亮，浮窗显示快速信息（地价、持有者、建筑类型、当前收入/维护费）
- **鼠标单击**：选中地块，右侧面板加载完整信息
- **鼠标拖拽**：平移地图
- **滚轮**：缩放（四级缩放：区域视图 → 街区视图 → 地块视图 → 建筑特写）

每一级缩放切换不同的信息密度：

| 缩放级别 | 显示内容 |
|---|---|
| 城市全景 | 各区域颜色热力图（地价高→红，地价低→蓝），自己持有的地块以金色轮廓标出 |
| 街区视图 | 建筑剪影 + 有轨电车路线 + 地铁站标识 |
| 地块视图 | 单个建筑的详细外观、门前街道的行人和车辆（纯氛围，无玩法功能） |

### 7.3 拍卖厅界面

拍卖是游戏中最紧张的场景，对应的 UI 需要有仪式感：

- 拍卖开始时，画面中央出现拍卖台（Art Deco 风格的讲台和木槌动画）
- 出价面板在屏幕下方：当前最高价、下一个加价台阶、你的剩余可用资金、10 秒倒数计时条
- AI 对手以橡皮管风格的半身立绘出现在屏幕两侧，每次出价时他们的立绘会有对应的表情变化（得意、犹豫、恼怒、放弃）
- "咚"一声（木槌敲击）——"Sold！"——拍卖结束

### 7.4 资产总览界面

玩家随时可以打开，俯瞰自己的帝国全景：

- 左侧：按城市分类的资产清单（每项资产列出：购买价格、当前市值、每回合收入/维护费、持有回合数、是否处于他人"恶意收购"威胁中）
- 右侧：饼图——你的资产分布（住宅/商业/工业/交通） vs 行业平均分布
- 底部："你的帝国在哪个方面最脆弱"——由系统根据目前 AI 持有情况和你的资产暴露度给出五个词以内的警告（如："中城区工业用地暴露"，意思是你的中城工厂群正在被 Tycoon 盯上）

## 八、游戏流程

### 8.1 开局（回合 0）

1. 玩家看到纽约地图（大量空地的中城区域被高亮提示）
2. 信息卡弹出：简短开场——"1925 年春，纽约。你从已故的叔叔那里继承了五万美元现金和一笔银行贷款额度。中城那些空地已经在你的目光里燃烧了半年。那个叫科尼利厄斯的秃头——听说他上个月买下了八块地。贝阿特丽斯在第五大道上已经有了两栋公寓。而索尔——索尔告诉每一个人：他从不建东西，他只买和卖。"
3. 玩家被给予第一次行动点数（现金 $50,000 + 信用 $100,000），自由选购第一块地

### 8.2 每回合结构

每回合包含四个阶段：

**阶段一：收入结算**
- 所有建筑自动产出现金收入
- 所有建筑自动扣减维护费
- 信用利息自动结算
- 事件随机触发（全局或局部）

**阶段二：行动阶段**（玩家自由执行，顺序不限，最多执行 3 次行动）
- 行动类型：购买空地、建造建筑（建在已持有的空地上）、进入交易所发起产权交易、对 AI 发起恶意收购、进入拍卖厅（如果有正在进行的拍卖）、与某位 AI 进行"私人谈判"（提议互换某两块地、提议共同投资某条铁路等——AI 接受/拒绝/还价）

**阶段三：AI 行动**（AI 以同样的行动规则并行行动，玩家可以看到他们的行动在事件日志中滚动更新）

**阶段四：回合结束**
- 更新所有地块的地价（受所有玩家本回合行为影响——新建的铁路拉升周边、新建的工厂压低周边住宅）
- 更新经济阶段（若到达周期切换节点则触发阶段切换事件）
- 更新银行的利率政策（依据经济阶段）
- 进入下一回合

### 8.3 胜利条件

Demo 版本暂设单一胜利条件：**第一个积累到 $500,000 资产总值**（现金 + 信用可用额度 + 所有持有的地产当前市值）的玩家触发终局倒计时。倒计时为 3 回合。

在倒计时的三个回合中：
- 领先者的信用额度被冻结（不能新增贷款）
- 其他玩家可以对领先者发起无限制的恶意收购
- 其他玩家之间可以暂时结盟（互相交易资产来凑足超越领先者所需的资本——"敌人的敌人就是暂时不打我的人"）

若领先者在倒计时结束后仍保持第一，则获胜。若在倒计时期间被另一玩家反超——倒计时重置，新的领先者开始新的 3 回合倒计时。

**设计意图**：最后三个回合是整个游戏中最激烈的阶段——不是走形式，不是等结束，而是所有人都知道"这是最后一搏"时的全情投入。

## 九、Demo 开发里程碑

| 里程碑 | 内容 | 验证标准 |
|---|---|---|
| **M1：可走的地图** | 纽约曼哈顿地图渲染完成，手绘风格 + 地块网格，可拖拽、缩放、点击选中地块 | 地图滚动无掉帧（稳定 60fps），地块选中高亮响应即时 |
| **M2：可买的地** | 空地购买流程完成（从点击空地到支付到地块归属权变更），地价计算逻辑生效（基础价 + 相邻加成） | 三遍重复测试，每次在不同区域买地，确保最终持有数量正确、现金扣减正确 |
| **M3：可建的楼** | 四种建筑建造流程完成（从选择地块到选择建筑类型到建造完成到每回合产出收入/扣减维护费） | 三种建筑同时在手，收入—维护费净额在每回合结算后数字正确 |
| **M4：可拍的卖** | 拍卖厅完整流程（竞拍触发、竞拍 UI、英式增价拍卖逻辑、AI 竞拍行为、落槌成交） | 两块地同时被触发竞拍的并发状态不崩溃；人机混拍中 AI 不会无限出价也不会在第一轮全退 |
| **M5：可交易的凭证** | 资产交易所三种交易模式完成（挂牌、封闭竞标、恶意收购），AI 在这三种模式中的行为逻辑完备 | 所有可能的交易场景（玩家主动发起、AI 主动发起、AI 对 AI、恶意收购触发毒丸反击）各自跑通一次 |
| **M6：可跑的完整一局** | 经济周期完整运行一次（50 回合）、胜利条件触发、终局倒计时、游戏结束 + 胜利/失败画面 | 一局游戏从回合 0 到自然结束（不硬切、不报错），所有结算数字在全过程中可审计 |
| **M7：可玩的 Demo** | 美术资源全替换（不再有占位几何体），声效/音乐接入，tooltip 覆盖全部 UI 元素 | 从未接触过项目的测试者可以在无外部指导下完成首次购地、首次建造、首次参与拍卖 |

## 十、技术建议

### 10.1 引擎

**推荐 Unity**。原因：
- 2D 骨骼动画（橡皮管角色）有成熟的 Spine / Unity 2D Animation 套件
- 地图拖拽 + 缩放 + 地块点击在 Unity 2D 中有大量社区方案
- 跨平台发布（PC → 移动端/主机）路径清晰 — 如果 Demo 效果好后续想上 Nintendo Switch，Unity 是阻力最小的

### 10.2 数据结构

每块地不是"一个游戏对象"，是**一个数据条目**，挂在一个集中的"地块管理器"中：

```csharp
public class LandTile {
    public int id;
    public Vector2Int gridPosition;  // 地块在地图网格中的坐标
    public string zone;              // "residential" / "commercial" / "industrial" / "mixed" / "public"
    public int landValue;            // 当前市场地价（美元，整数）
    public Building currentBuilding; // 当前建筑（可为 null）
    public int ownerId;              // 持有者 ID
    public int[] adjacencyIds;       // 相邻地块的 ID 数组
}
```

这样设计的好处：地图上同时存在约 200—300 个地块时，更新逻辑只需遍历一次数组，而不需要遍历所有 GameObject。渲染和逻辑分离——地块的视觉呈现（建筑外观变化、高亮轮廓等）由视图层根据数据变化触发更新，而不在每帧轮询。

### 10.3 AI Debug 可观测性

在 Demo 阶段，为 AI 的每一个决策提供**debug 可视化**：

- 按 `F1` 键打开 AI 决策日志：每一行显示"AI-B 在第 12 回合对地块 #47 出价 $8,200；估值算法给出 $7,800—$9,100 区间，当前出价在区间内"
- AI 头像旁边的数值条实时显示其"当前攻击性"和"现金紧张度"
- 视觉上：AI 正在评估的地块以他的人格色（Tycoon=棕色，Landlady=紫色，Shark=银色）微微闪烁

这不是最终面向玩家的功能，但在迭代阶段极有价值——当你发现某个 AI 在连续三局中犯了同样的策略错误时，你能看到它在做什么。设计意图是：开发过程中对 AI 行为的错误保持可观测，而不是做成黑盒然后在用户反馈里猜测 AI 哪里不对。
