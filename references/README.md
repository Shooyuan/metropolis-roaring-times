# 原始设计参考

当前项目正式名称为 **Metropolis: Roaring Times**。本目录中的原始 PRD 保留旧工作名是历史资料状态，不代表当前产品标题或实施范围。

本目录保存设计依据，不是唯一实施规格。当前收录以下原始文件：

- `manhattan_map_reference.jpg`
- `PRD_纽约地图Demo_v0.1.md`
- `PRD_法令系统与游戏模式_v0.2.md`

实施时应先将原始设计转化为 `docs/` 中可验证的规格；不要直接把本目录中的材料当作唯一实施标准。

`manhattan_map_reference.jpg` 以及后来提交的地图、徽章和天际线图片都只作为美术、构图或素材候选参考。1939 地图不会直接作为发布版背景。生产底图与分区边界由老板在 Figma 中创作并批准，Codex 不得自行绘制或猜测。具体尺寸、页面、图层、文件名和登记规则见 `../docs/MAP_ASSET_PIPELINE.md`。

正式地图交付包先原样放入 `references/incoming/metropolis_map_vNNN/`，必须包含版本化 `.fig`、插件快速交付 ZIP 与老板说明。ZIP 至少包含完整结构 JSON、纯底图 SVG、分区 SVG、历史地标 SVG、可购买地块 SVG 和原始图片；完整主画框、对齐合成预览、逐层 SVG 与 PNG 只属于完整归档模式的可选输出。Codex 完成校验并获得老板确认前，不得把派生文件移入 `assets/` 或 `data/`。

新加入但尚未登记来源、用途和权利状态的文件必须保持原样，不得擅自重命名、修改、转码、加入发布包或提交 Git。完成素材登记与老板批准后，才可移动到正式 `assets/` 目录并写入资产清单。
