# 历史内容审批区

本目录用于老板审查街区与历史地标资料，内容在老板标记“批准”前不进入正式游戏事实。

## 固定规则

1. 事实资料只选自 English Wikipedia；中文是同一英文条目的翻译与改写，不从中文 Wikipedia 拼接新事实。
2. 保存英文页面标题、URL、访问日期、事实检查状态和老板审批状态。
3. 只做摘要改写，不大段复制原文。文风可以像一位克制而机智的城市向导，受 Mark Twain 的观察力启发，但不模仿原句、不用网络梗、不写时代错置笑话。
4. 中文短介绍约 20 字、长介绍约 200 字；英文短介绍 8—15 词、长介绍 100—150 词。两种语言事实一致，但不要求逐字直译。
5. 当前完整地标清单和 Figma 位置尚未交付，因此本目录暂不编造条目。
6. 历史地标对玩法的影响全部标记为“延期”，进入相关阶段前由 Codex 主动提醒老板审批。

## 审批流程

1. Codex 根据老板完成的 Figma 提取稳定 ID 与英文地图名。
2. Codex只读 English Wikipedia，填写模板和来源台账。
3. 老板逐条审查名称、事实、文风、插画对应和是否采用。
4. 只有 `APPROVAL_REGISTER.md` 标记为“老板批准”的记录才能转换为运行时内容。

`districts/README.md` 与 `landmarks/README.md` 分别保存将来的审核稿；模板在 `templates/`。
