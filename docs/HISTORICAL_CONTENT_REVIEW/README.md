# 历史内容审批区

本目录用于老板审查街区与历史地标资料，内容在老板标记“批准”前不进入正式游戏事实。

## 固定规则

1. 事实资料只选自 English Wikipedia；中文是同一英文条目的翻译与改写，不从中文 Wikipedia 拼接新事实。
2. 保存英文页面标题、URL、访问日期、事实检查状态和老板审批状态。
3. 只做摘要改写，不大段复制原文。文风可以像一位克制而机智的城市向导，受 Mark Twain 的观察力启发，但不模仿原句、不用网络梗、不写时代错置笑话。
4. 历史地标中文短介绍固定为“建筑名，单句描述”，英文短介绍同步采用“名称 + 一句描述”的简洁结构；中文长介绍约 200 字，英文长介绍 100—150 词。两种语言事实一致，但不要求逐字直译。
5. 当前 52 个历史地标的运行时名称、短介绍、长介绍和逐项来源已录入；中文权威正文见 `../LANDMARK_COPY_DRAFT.md`，运行时双语正文见 `../../m0_web/landmark-content.js`。本目录继续承载来源复核和后续新增内容的审查记录。
6. 历史地标对玩法的影响全部标记为“延期”，进入相关阶段前由 Codex 主动提醒老板审批。

## 审批流程

1. Codex 根据 Figma 交付提取稳定 ID 与英文地图名。
2. Codex 只读 English Wikipedia，填写模板和来源台账。
3. 项目负责人逐条审查名称、事实、文风、插画对应和是否采用。
4. 审查通过的内容转换为运行时数据；当前已采用的 52 条以 `LANDMARK_COPY_DRAFT.md` 和 `m0_web/landmark-content.js` 为准。

`districts/README.md` 与 `landmarks/README.md` 分别保存后续审核稿；模板在 `templates/`。
