## 三、真实浏览器验收

使用本地 HTTP 服务器打开隔离快照，完成以下路径：

1. 启动页进入新对局并选择 Tycoon；
2. `100%` 点击历史地标，确认只选择其所属街区，地标本身不被选择；
3. 连续放大至 `500%`，确认加号禁用、地块命中开放、地标横幅显示；
4. 选择 `plot_001`，确认右侧切换为 Property File，且街区和地标选择被清除；
5. 购买 `plot_001` 后现金从 `$50,000` 变为 `$41,000`、行动点从 `3` 变为 `2`；
6. 建造 Standard Apartment 后现金变为 `$33,000`、行动点变为 `1`，状态为 Building；
7. 选择 Empire State Building，确认右侧切换为 Historical File，且地块和街区选择被清除；
8. 点击地图空白，确认三类选择全部清空，右侧恢复 Map File；
9. 切换简体中文，确认对局回合、`500%` 镜头和选择状态不重置，动态地图状态更新为“12 个街区 · 30 个地块 · 52 个地标”；
10. 检查页面 117 个 `img` 元素，无加载失败；浏览器控制台无 warning/error。
