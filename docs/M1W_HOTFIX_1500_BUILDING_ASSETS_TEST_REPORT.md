# M1W 1500% 缩放与通用建筑贴图测试报告

日期：2026-09-11

## 本次目标

- 把地图最高缩放从 `1000%` 提高到 `1500%`；
- 保留 `500%` 作为地块、开发建筑和历史地标点击的精细交互起点；
- 设置 `1250%—1500%` 显示历史地标英文横幅；
- 接入老板上传的五张通用建筑 PNG：工地、普通公寓、豪华公寓、商店和工厂；
- 购买地块后立即显示工地，建造或改建完成后显示对应建筑；
- 英文游戏内界面统一使用 `InknutAntiqua-Regular.ttf` 对应的 `Inknut Antiqua M1W`；
- 缩小可购买地块价格标注，降低地图拥挤感。

## 实现结果

1. 固定缩放档位更新为 `100/125/156/195/244/305/381/477/500/625/781/977/1000/1250/1500%`。
2. `100%—477%` 仍为街区浏览层级。
3. `500%—1500%` 开放地块、开发建筑和地标点击。
4. `1250%—1500%` 显示历史地标英文横幅；`1000%` 时横幅仍隐藏。
5. 五张中文源文件复制为网页运行时英文稳定文件名，避免中文路径和部署编码风险。
6. 购买后、未建造或施工中的地块显示 `construction_site.png`；建成后显示对应建筑 PNG。
7. 英文游戏界面、弹窗和提示统一使用 `Inknut Antiqua M1W`；中文模式不强行套用英文字体。

## 已知风险

- 建筑贴图目前按地块外接矩形中心和安全尺寸自动放置；细长或不规则地块可能需要后续人工锚点微调。
- AI 开局持有但未建造的地块也会显示工地；这符合“买下之后即显示工地”的当前规则。如果老板希望 AI 未建造地块使用独立状态，需要另行审批。
- 历史地标横幅来自现有 Figma 导出 SVG，当前仅通过 CSS 放大展示；若个别横幅文字本身过长，仍可能需要回 Figma 调整源横幅。
