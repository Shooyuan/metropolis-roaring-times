# M1W 启动弹窗与 1000% 缩放修复测试报告

- 恢复启动页及对手选择弹窗的纸张面板贴图；
- 把地图最高缩放由 `500%` 提高到 `1000%`；
- 保留 `500%` 作为地块、开发建筑和历史地标横幅的精细交互起点。

## 自动测试门槛

1. 页面所有面板引用均指向实际存在的 `assets/home_png_complete/panel_center_large.png`。
2. 固定缩放档位精确为 `100/125/156/195/244/305/381/477/500/625/781/977/1000%`。
3. 最小值钳制为 `100%`，最大值钳制为 `1000%`。
4. `100%—477%` 维持街区浏览；`500%—1000%` 维持地块和地标精细交互。
5. 英文与简体中文提示共用同一运行状态，切换语言不得重置镜头。

## 真实浏览器门槛

1. 从启动页打开对手选择弹窗，不出现破图图标，面板和三个选项均显示纸张贴图。
2. 从 `100%` 连续放大到 `1000%`，百分比逐档正确；到顶后加号禁用。
3. 在 `500%` 与 `1000%` 分别验证地块或历史地标仍可选择。
4. `1000%` 下拖拽仍受边界约束，地图不能完全丢出视口。
5. 控制台无新增错误，页面图片资源全部成功载入。
