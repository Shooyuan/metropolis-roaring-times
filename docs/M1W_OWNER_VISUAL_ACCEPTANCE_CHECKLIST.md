# M1W 网页视觉验收清单

> 日期：2026-09-13
>
> 对象：`m0_web` 制作人网页原型
>
> 目的：让老板逐项审查 v004 地图、地块、地标、缩放、文案和当前网页可读性。通过本清单不代表批准 Godot M1A、最终 UI 或 20 回合正式平衡。

## 运行方式

在项目根目录双击 `run_metropolis_demo.command`，或在 `m0_web` 目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/
```

如浏览器仍显示旧字体、旧辉光或旧贴图，先执行硬刷新：`Cmd + Shift + R`。

## 老板需要逐项审查

### 1. 启动页与进入流程

- 首页 Brand 是否完整显示 `Metropolis: Roaring Times`。
- 启动页背景、票据、天际线、面板贴图是否可接受。
- New Game、Load、Config、About 的入口是否清楚。
- 选择 Tycoon、Landlady、Shark 后能顺利进入对局。

记录问题：

```text
无 / 有：
```

### 2. 地图整体阅读

- `100%` 下曼哈顿整体形状、河流、中央公园和街区边界是否易读。
- 地图不能横倒、旋转或丢失主要方向。
- 街区标签是否在英文和中文界面下都固定显示英文地图名。
- 多词街区是否一词一行，例如 `UPPER / EAST / SIDE`。
- 街区标签默认色 `#bdb199` 是否舒适，悬停/选中深色 `#4e403e` 是否清楚。

记录问题：

```text
无 / 有：
```

### 3. 缩放与 LOD

- `100%—477%`：街区浏览清楚，地块/地标不应误选。
- `500%`：地块、开发建筑和历史地标可以直接点击。
- `1000%`：细小地块和历史地标应可检查，但历史地标横幅仍隐藏。
- `1250%—1500%`：历史地标横幅显示，不能明显遮挡主要判断。
- 加号、减号、重置和当前百分比显示是否符合直觉。

记录问题：

```text

```

- 地块 hover/选中是否清楚，不能和街区或地标状态混淆。
- 购买后显示工地，建造完成后显示对应通用建筑 PNG。
- 细长或不规则地块上的建筑位置是否可接受；如不可接受，记录具体地块 ID。
