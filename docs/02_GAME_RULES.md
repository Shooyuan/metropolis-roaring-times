# 游戏规则

> 状态：待根据原始 PRD 校准。本文是代码实现的规则入口，不以 `references/` 文件直接驱动实现。

## 一局游戏

- 固定进行 20 回合，除非触发实施规格中明确列出的提前失败条件。
- 每回合依次经历：局势更新、法令选择、效果结算、地图与指标反馈、进入下一回合。
- 第 20 回合结算后进入最终结果界面，不再接受行动。

## 玩家行动

- 玩家每回合从当前可用法令中选择一个行动，或使用规格明确允许的跳过操作。
- 法令必须展示即时影响；延迟影响应标明持续时间或触发条件。
- 不允许同一输入重复结算，也不允许结算后返回修改本回合选择。

## 城市状态

- 指标、区域状态、法令条件和胜负阈值必须集中配置。
- 数值范围、初始值、具体法令和胜负条件需在读取两份原始 PRD 后补齐并冻结。
- 每次结算必须可追溯：界面能够说明哪些变化来自本回合法令或规则事件。

## 随机性

- 若垂直切片采用随机事件，必须支持固定种子以便验收复现。
- 随机结果不得改变文档定义的回合结构和完成条件。
