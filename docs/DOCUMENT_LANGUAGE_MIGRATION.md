# 《Metropolis: Roaring Times》开发文档中文化清单

> 用途：修正早期开发文档主要使用英文的问题，同时避免翻译过程改变已经批准的规则、数值和技术标识。
>
> 本文件只管理文档语言，不改变游戏范围或玩法。

## 一、语言边界

- 项目负责人需要审查的项目计划、产品规则、风险、验收、美术交付说明和阶段报告必须以中文为主。
- 游戏界面、新闻、事件、角色对话、按钮和提示默认面向英语用户，因此保持英文。
- 产品名、软件名、文件名、代码标识、内容 ID、Figma 页面/图层名和其他需要稳定匹配的技术字段保持英文。
- 中文开发文档引用玩家实际看到的文字时，保留英文原文并在需要时附中文解释。

## 三、每个翻译批次的固定流程

1. 开始前向项目负责人报告本批次包含哪些文件、哪些内容不改变以及主要风险。
2. 只翻译说明文字；不改变任何数值、公式、验收编号、文件名、稳定 ID 和玩家英文文案。
3. 将中文译文逐节与原文规则对照，检查是否出现遗漏、范围扩大或条件反转。
4. 检查 Markdown 链接、标题层级、验收编号和跨文档术语。
5. 运行 Godot 基线测试，证明只改文档没有破坏工程。
6. 修复问题后创建单独的 Git 提交。
7. 停下来向项目负责人报告结果，不自动进入下一批。

## 四、当前优先级

当前需要项目负责人审查的地图交付规范和项目管理计划已经先行中文化。其余翻译批次不得与实际 M1A 地图开发混在同一个提交中；先由项目负责人决定是优先完成全部文档中文化，还是在不影响审查的前提下与后续里程碑交替进行。
