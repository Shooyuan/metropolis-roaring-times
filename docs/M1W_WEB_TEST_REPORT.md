## 一、本阶段交付

M1W 将老板批准的 Figma 地图交付包 v003 接入原有 M0.1 网页，形成制作人可操作的地图演示：

- 正式独立 Brand；
- 正式地图底图；
- 12个老板批准的分区几何；
- 鼠标拖拽、滚轮缩放、按钮缩放和键盘操作；
- 固定倍率缩放与禁止旋转；
- 分区悬停边框、点击锁定、关闭选择和英/简中详情；
- 原状态栏、综合操作栏、新闻、银行、股票和八回合经济说明。
- 单一 `index.html`、单一玩法脚本和两份语言词典；
- 设置内即时语言切换、英文首次默认、选择记忆和 `?lang=zh-CN` 直达；
- 统一存档键、旧英文/旧中文存档只读迁移来源和旧 `/zh-CN/` 链接兼容。

网页没有自行创建64个地块，也没有把旧18个灰盒地块猜测或迁移到正式地图。旧数据只作为无地理含义的经济测试夹具留在代码中，不显示在地图上。

## 七、公开风险与后续门禁

1. 正式 Brand SVG 约4.1MB，地图底图约834KB。本地演示加载正常，但正式公网版本应在不改变视觉的前提下制作轻量网页副本并重新对比；权威源文件不压缩覆盖。
   此外，正式 Brand SVG 内嵌一张 `2280×930` PNG，因此 Brand 不是完全矢量；当前页头尺寸可用，但未来超大倍率展示仍可能模糊。Codex 不得擅自重画，需由老板决定是否要求 Figma 提供纯矢量 Brand。
2. 当前只有分区交互，没有64个正式地块；任何购买、建筑、所有权和繁荣度数字仍显示为待批准，不使用伪数据。
3. 分区标签是网页运行时标签，不是老板底图的一部分；老板可以在本次视觉验收中要求字号或位置调整。
4. 本报告只通过 M1W 网页门，不授权 Godot M1A。
